# Website design continuity

All new website features must use the existing War Maps theme and design.
Reuse shared theme variables, typography, controls, spacing conventions, and
page structure. Do not introduce a separate palette or visual language.
Canvas and other programmatically drawn surfaces must follow the active theme
and update when it changes. Keep requested data-category colors consistent
with their legends and readable against the theme.

The death-circle print poster is the design master for Conflict Sides on the
website and in print. Preserve its composition and the relationships between
dots, the side circle, side names/counts, civilians, and unknown deaths. Order
sides by casualties with the fewest at the top; use black for the smaller A/B death count and red for the larger count,
regardless of source-side identity. Use the website theme for web surfaces without discarding the poster
composition. Make changes in source/generator files and update outputs.

Preserve unrelated workspace changes.
