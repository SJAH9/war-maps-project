Organized conflict

UCDP observations and event records

Conflict layers use Uppsala Conflict Data Program records. The global register is built from conflict-year observations; candidate-event records provide dated places and fatality estimates where loaded.

What map counts mean

Conflict-map color counts distinct loaded conflict records intersecting the selected window and state. It is not territorial control, military effectiveness, force size, spending, or a fatality rate. Candidate-event markers are provisional records at the source boundary.

Parties and relationships

Side A and Side B reproduce source-side coding within a conflict. Same-side links are conflict-specific observed relationships, not permanent alliances. Opposing-side links do not imply an enduring diplomatic category. The network preserves this distinction.
