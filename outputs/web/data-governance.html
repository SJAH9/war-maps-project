Government forms

V-Dem regimes, conditions, and transitions

Governance layers use V-Dem country-year observations. The map’s four-category selector follows the Regimes of the World coding used in the loaded V-Dem extract.

Closed autocracyV-Dem code 0
Electoral autocracyV-Dem code 1
Electoral democracyV-Dem code 2
Liberal democracyV-Dem code 3

“Totalitarian dictatorship” is not a separate category in this four-class variable. Questions framed that way can inspect the available closed-autocracy class, but the atlas does not silently rename it or claim equivalence.

Transitions

A transition marker appears when a country’s regime code changes between adjacent loaded country-years. The health comparison groups mortality and fertility observations by the regime code for the same country-year. These are descriptive associations. They do not establish that regime type caused a health outcome.

Conditions

Nation records may expose additional loaded V-Dem indicators as state conditions. Their values remain bounded by the V-Dem methodology, uncertainty, coverage, and version used by the build.
