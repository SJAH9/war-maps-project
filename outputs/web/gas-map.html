How to compare

All displayed prices use USD per U.S. gallon. The selected-place panel also shows the indicative USD-per-litre conversion. Both use the dated ECB exchange-rate reference (Taiwan uses the central bank’s TWD/USD close). Original source values remain in the data; the snapshot is not a live feed. Missing places are not zero-price places.
