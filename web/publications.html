War Maps in print

Read, print and adapt the curated 2026 poster collection. Both ebooks include the project's About and Sources content, source links and QR routes to the atlas and its code.

Rebuild and reuse

Clone the repository, install requirements.txt, and run python -m src.generate_publications. The explicit publication selection controls both ebooks. Retain source attribution when using the posters in art, media, teaching or public discussion. The Ephemeris and unselected network studies are not part of this release.

Roadmap

This is the last meaningful War Maps release planned for 2026: a solid first year. Next come a network-science and cybersecurity-focused ebook, improved network interfaces and visual language for dense event records, and data-source upgrades with clearer source-version tracking.
