War Maps on your device

Install War Maps

War Maps can be installed as a standalone web app on supported mobile and desktop browsers. Open the site online once before using its offline reading pages.

Android and desktop

Use the Install War Maps button when your browser offers it, or choose Install app from the browser menu.

iPhone and iPad

In Safari, open the Share menu and choose Add to Home Screen, then Open as Web App if offered.

Partial offline access

The start page, About, Sources, installation guide and publications index are saved on your first successful visit. Small same-origin resources visited online can also be retained in a bounded cache. Live news, external map libraries and tiles, large datasets and PDF downloads require a connection unless separately downloaded. Installing the app does not download the whole atlas.

Offline pages reflect the last saved version; reconnect to refresh them. Browser storage can be cleared or evicted. To remove saved content, clear this site's storage in your browser settings.
