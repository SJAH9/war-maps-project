How to navigate

Rotate: click and drag empty space. Zoom: scroll or use the fit button.

Move a node: drag it; release to give it momentum. Connected nodes follow gradually. Optimize: lays the selected network out in 3D, with connected nodes grouped around hubs.

Selection: selecting a node makes it central and loads all of its immediate recorded connections. Select any connected node to continue through the archive. Search and organization checkboxes can start a new path.

Optimization landscapes: each arrangement emphasizes a different structural feature while retaining the same observed edges. No optimization fabricates a relationship.
